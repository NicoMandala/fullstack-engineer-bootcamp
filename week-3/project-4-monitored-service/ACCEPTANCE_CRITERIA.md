# Acceptance criteria

- [ ] Run API locally without startup errors.
- [ ] Feature routes no longer return placeholder HTTP 501.
- [ ] Valid actions result in expected persistent-for-process state changes.
- [ ] Invalid requests return clear 4xx responses.
- [ ] Domain code remains independent of FastAPI and infrastructure.
- [ ] At least four meaningful non-smoke tests pass.
- [ ] Demo and include evidence of requests, responses, tests and screenshots.
