# Four-week curriculum

Days 1-3: Complete [Kaggle Python](https://www.kaggle.com/learn/python), then [FastAPI's tutorial](https://fastapi.tiangolo.com/tutorial/). Write exercises on functions, dictionaries, exceptions and API requests.

Day 4: Project 1 Task API. Day 5: Project 2 Ticket API.

Days 6-8: Dockerize Project 3. Days 9-10: CI/CD, tests, deployment demo.

Days 11-13: Structured logs, request IDs and metrics for Project 4. Days 14-15: Grafana dashboard, debug three injected failures.

Days 16-18: Build integrated Project 5 with AI-generated frontend. Days 19-20: Test, deploy, document, present and defend architecture.

Daily routine: plan, code, test, document, demo. Each deadline requires commit history and a short explanation of decisions.
