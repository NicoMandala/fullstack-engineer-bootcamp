# Full-Stack Engineer Bootcamp

Four-week guided backend-first engineering program with five projects using Python, FastAPI, Uvicorn, onion architecture, Docker, GitHub Actions CI/CD, logging, Prometheus and Grafana.

This is an educational starter, not finished solutions. Each week gives progressively less scaffolding.

## Weekly projects

- `week-1/project-1-task-api`: Task Management API, Day 4
- `week-1/project-2-ticket-api`: Support Ticket API, Day 5
- `week-2/project-3-deployable-helpdesk`: Docker + CI/CD, Days 6-10
- `week-3/project-4-monitored-service`: Logging and monitoring, Days 11-15
- `week-4/project-5-operations-portal`: Integrated capstone, Days 16-20

The full 156-file starter ZIP was prepared separately. Do not consider any project completed because the app's health endpoint works. Feature routes are intentionally unimplemented.
